# YOLO AI Safety Analyzer

An AI-powered video safety analysis system using YOLO and OpenCV to detect objects and identify potential safety risks in video footage.

## Features
- Video-based object detection
- Automated safety monitoring
- Visual detection with bounding boxes
- Annotated video output

## Technologies
- Python
- YOLO
- OpenCV
- Computer Vision
- Deep Learning

## Project Purpose
To improve safety monitoring through automated AI-based video analysis.
